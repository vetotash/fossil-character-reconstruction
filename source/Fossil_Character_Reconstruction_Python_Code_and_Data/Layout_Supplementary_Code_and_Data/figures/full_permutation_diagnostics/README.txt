FULL O/U/T PERMUTATION DIAGNOSTICS

This retained three-panel diagnostic is not the current main-text Figure 2.
It shows only the empirical-minus-full-O/U/T-permuted contrasts for Brier
score, absolute error of mean D and CRPS. It contains no fixed-target contrasts.
The original numerical inputs and output graphics are retained without a change
to any scientific value. Output filenames and the plotting script name now
distinguish this diagnostic from figures/figure2/.

To reproduce these diagnostics from any working directory, invoke the absolute
path to plot_full_permutation_diagnostics.py with --output-dir NEW_DIRECTORY.
Its inputs are resolved relative to the script. The historical two-metric input
table name inside inputs/ is retained solely for provenance.
