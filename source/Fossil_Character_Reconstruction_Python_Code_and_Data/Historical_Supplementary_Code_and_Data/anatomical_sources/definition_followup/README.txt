Additional documentary review of character correspondence and OTU scope
Review date: 2026-10-05

This is an additive, initially AI-assisted author documentary review made after
the original fixed 100-endpoint audit and after prior aggregate results were known.
The authors have subsequently independently verified its source-based judgements
and scientific interpretations; see ../../AUTHOR_VERIFICATION_STATEMENT.txt.
This completed human verification is not a new anatomical-expert assessment or
a new preregistered sample. No prediction performance was used as evidence in these decisions.
No original 100-endpoint record, eligibility rule, state label, model input,
prediction, or numerical result has been replaced.
The revised Supplementary Information presents the definition follow-up in
S16.2 and the added Inherited column of Table S30, and the OTU decisions in
S16.5. The Inherited column refers to this dinosaur follow-up only; the original
Def evidence category must not be described as exclusively repeated definitions
across all five histories.

Dinosaur correspondence
The original audit classified only character 97 among the twenty dinosaur
entries as supported, because its definition was repeated in the later source.
For the other nineteen, the original printed definition had already been read;
the unresolved category reflected absence of a later reprint, not a missing
original definition or an identified semantic conflict. The additional review
re-retrieved the two original publisher PDFs and confirmed that their SHA256
hashes equal the original source_index records S004 and S005. Langer SI section
1.1, page 1 explicitly identifies its list as scoring modifications to the
original Baron matrix. Each sampled entry was traced from the original numbered
definition to its taxon-specific numbered modification. The extra evidence is
therefore documented inheritance, distinct from a two-version definition
comparison and from independent anatomical validation. No altered definition
was identified for these twenty sampled characters in the inspected later SI.

Original Def counts remain 78/100 overall and 1/20 for dinosaurs. The additional
inheritance column records 19 dinosaur entries, giving 97 entries with either
the original support classification or this additional documentary route.
This combined count is not a count of independently validated anatomy.
Later-state support remains 50/100. Laquintasaura character 366 retains its
existing conflict: original binary definition, later modification-list state 2,
later matrix state 0. No alternative state is inferred or substituted.

Files
- dinosaur_correspondence_followup.json: twenty endpoint-level records and source
  chains, evidence routes, native-matrix check results, and remaining limits.
- dinosaur_correspondence_followup.csv: flat endpoint table suitable for audit.
- locator_corrections.csv: precise modification pages where the original

  across Baron pages 54-55. Original audit files remain unchanged.
- otu_scope_decisions.json/csv: actual history-specific admission/exclusion
  decisions, their timing and archived evidence. They do not assert a uniform
  rule invented after the fact. The Suevoleviathan terminal merger removes
  25 otherwise eligible candidate cells; nine more cells also failed other
  criteria. It must not be described as removal of one target cell.
- source_evidence_revision.json: combined evidence and manuscript suggestions.
- verify_followup.py: validates record identity, unchanged original review hash,
  native-matrix tokens, counts, precise-page table and candidate exclusion
  accounting. It does not certify anatomical interpretation or reproduce the
  visual documentary reading.
- verification.json: this follow-up's structural/token check result only.
- MANIFEST.json: local checksums for this additive directory, excluding itself.
